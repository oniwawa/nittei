プライバシーポリシー

制定日：2026年11月10日　最終更新日：2026年11月10日

にっていじ運営（以下「運営者」）は、日程調整アプリ「にっていじ」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 取得する情報

本アプリは、利用者が「Googleカレンダーと連携」を行った場合に限り、Google から次の情報を取得します。

  • Googleカレンダーで表示中に設定されているカレンダーの一覧（カレンダーの ID）
  • 指定した期間のうち、予定が入っている時間帯（開始時刻と終了時刻のみ）

予定の名前、場所、説明、参加者、メールアドレスなど、予定の内容は取得しません。 本アプリが Google に求める権限は、次の 2 つの読み取り専用の権限だけです。予定の作成・変更・削除は行いません。

  • カレンダーの一覧の参照（calendar.calendarlist.readonly）
  • 予定の空き・埋まり状況の参照（calendar.freebusy）

2. 利用目的

取得した情報は、利用者が指定した条件の中から、予定が入っていない時間帯を探して日程の候補を作り、画面に表示するためだけに使います。

3. 情報の保存と第三者への提供

  • 取得した情報は、利用者のブラウザの中だけで処理し、運営者のサーバーやその他の外部に送信・保存しません。 ページを閉じる、または「連携を解除」を押すと、ブラウザからも消えます。
  • Google から受け取るアクセストークン（連携の許可）は、約 1 時間で無効になり、ブラウザ内に保存しません。
  • 取得した情報を第三者に提供・販売したり、広告に使ったりすることはありません。
  • 入力した条件や作成した文章も、運営者には送信されません。

4. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的な使用の要件を含め、 Google API サービスのユーザーデータに関するポリシー に従います。

にっていじ's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. 連携の解除

本アプリの「連携を解除」を押すと、Google 側の許可も取り消されます。 また、Google アカウントの「サードパーティとの接続」 から、いつでも本アプリへのアクセスを取り消せます。

6. 外部サービスの利用

  • 表示用の文字（フォント）を Google Fonts から読み込んでいます。その際、利用者の IP アドレスなどが Google に送信されます。
  • 本アプリは Vercel Inc. のサービス上で公開しています。ページを開いた際のアクセス記録（IP アドレス、ブラウザの種類など）が、 Vercel のサーバーに一時的に記録されることがあります。
  • 本アプリは、アクセス解析ツールや広告、Cookie を使っていません。

7. ポリシーの変更

本ポリシーは、必要に応じて変更することがあります。変更した場合は、このページで最終更新日とともにお知らせします。
